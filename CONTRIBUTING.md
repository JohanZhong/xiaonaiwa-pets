# Contributing

Small, reproducible improvements are welcome. Discuss new art styles before replacing any existing edition.

1. Fork the repository and create a branch.
2. Keep installation offline, checksum-verified and non-destructive by default.
3. Run `python scripts/validate.py` and `python -m unittest discover -s tests -v`.
4. Include before/after previews for animation changes, reviewed at native size and platform timing.
5. Explain what changed, why, and how you verified it. Update the changelog for user-visible changes.

Do not add private service URLs, credentials, personal account identifiers, local machine paths or third-party reference images without appropriate rights. Artwork contributions must explain their provenance and applicable rights. The code license does not authorize use of third-party characters.

Use clear, respectful language in issues and reviews. Report specific frames or steps instead of personal criticism.
