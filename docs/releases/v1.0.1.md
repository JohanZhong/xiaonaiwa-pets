# v1.0.1 · 修复经典 2D 眨眼时身体变色

之前的眨眼动画混用了原版身体与生成的中间帧，导致身体底色轻微闪变。

本次将六帧统一为同一张原版身体，只合成现有眼皮开合姿态，并匹配眼周底色。眼部区域之外的像素与透明轮廓完全一致。原有眨眼节奏、其他动作和 3D 素材保持不变。

- Added pixel-level regression checks for stable classic idle body color and alpha.
- Updated classic desktop WebP, Work PNG, legacy PNG and previews.
- Refined 3D artwork is unchanged.

Download `xiaonaiwa-2d-v1.0.1.zip` to update the classic edition, or `xiaonaiwa-pets-v1.0.1.zip` for both. Existing directories are protected by default; `--force` backs them up before replacement.

```bash
python scripts/install.py --variant 2d --force
```

Refresh the pet list after installation. In Work Pets, update the existing pet using `work-spritesheet.png`; desktop installation does not synchronize to Work.

Unofficial fan work; character art remains excluded from the MIT code license.
