# 小奶蛙双版本首次发布 / First dual-edition release

经典 2D 保留最早版动作并细化眨眼；精修 3D 提供更立体的软胶材质与独立动作。两版可同时安装，按喜好切换。

## Downloads

| File | Contents |
| --- | --- |
| `xiaonaiwa-pets-v1.0.0.zip` | 两版合集 / Both editions |
| `xiaonaiwa-2d-v1.0.0.zip` | 经典 2D 眨眼优化版 / Classic |
| `xiaonaiwa-3d-v1.0.0.zip` | 精修 3D / Refined |
| `SHA256SUMS.txt` | Download integrity hashes |

解压后把 `pets/` 下的文件夹放到 Codex 自定义宠物目录并刷新，或执行 `python scripts/install.py --variant all`。已有目录默认保留；使用 `--force` 会先备份再替换。

For Work Pets, use the edition's `work-spritesheet.png`. Desktop installation does not synchronize to Work. Legacy v1 PNGs are included for importers that explicitly require the older nine-row format.
