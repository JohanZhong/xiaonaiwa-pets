# Changelog

## 1.0.1 — 2026-11-11

- Fixed classic 2D body color flicker during blinking by sharing an identical body base.
- Added body-color and silhouette regression checks; kept all other actions and 3D art unchanged.

## 1.0.0 — 2026-11-11

- Introduced separately installable classic 2D and refined 3D editions.
- Preserved original classic actions and improved idle eyelid transitions within the fixed six-frame state.
- Added lossless desktop WebP, Work Pets v2 PNG and legacy v1 PNG for each edition.
- Added bilingual documentation, native-timing previews, offline verified installer, CI and reproducible release bundles.
- Separated the software license from fan-art and underlying character rights.
